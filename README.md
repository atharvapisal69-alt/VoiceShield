# 🛡️ VoiceShield

AI-Assisted Voice-Cloning Scam Risk Detection & Prevention Platform.

## 🎯 Objective

VoiceShield analyzes suspicious voice recordings and provides an AI-assisted risk assessment, understandable explanation, and safe verification guidance.
